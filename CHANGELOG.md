# Changelog

## Unreleased — hard fork (ayakalea-toolkit)

### Removed (SaaS & upstream baggage)
- `SERVER_PRO` flag and all Server-Pro gating logic; sandboxed compiles,
  git-bridge, external auth, S3 and the TLS proxy are first-class features.
- overleaf.com / "Server Pro" branding, links and wording; all docs now
  point to https://ayakaleaf-pro.ayaka.space.
- Podman/SELinux setup (`bin/podman-setup`, `podman_socket_clsi.te`,
  SELinux compose fragment) — Docker only.
- 20 scattered upstream doc pages (now hosted on the docs site);
  `doc/` keeps only the migration note.
- `config/version` as an image pin (legacy value is folded into
  `config/images.env` with a warning, so old deployments keep working).
- Pre-v5 variable legacy (`docker-compose.vars-legacy.yml`).

### Added
- **Optional container sets** (off by default, in `overleaf.rc`):
  - `LANGUAGE_TOOL_ENABLED` — real LanguageTool server (`languagetool`,
    v2 API :8010, n-gram dir, Java heap knobs).
  - `GRAMMAR_LLM_ENABLED` — `grammar-llm` LLM checker (LanguageTool-compatible
    API; ~2.4 GB GGUF model dir, auto-download on first start; cascades to
    real LanguageTool first when both sets are on — `GRAMMAR_LLM_CASCADE`).
    When both are enabled, the app points at `grammar-llm`.
  - `MONITORING_ENABLED` — prometheus-probe-grafana stack: `instance-sensor`
    (PR#178 instance stats), `node-exporter` (host), `mongodb-exporter` +
    `redis-exporter` + readiness probes, `prometheus` (TSDB + rules,
    :9090 on loopback) and `grafana` (provisioned datasource + dashboards,
    :3000). Grafana admin password generated by `bin/init`.
- **`bin/fetch-images`** — makes images available locally: pull from the
  configured source → `*_FALLBACK` ref (pull + retag) → local build from the
  bundled sources. **All five bridge images build from the Dockerfiles in
  `lib/images-build/`** (pandoc, pdftocairo, png2pdf, grammar-llm,
  instance-sensor); pdftocairo/png2pdf verified building and running.
- **SeaweedFS master** exposes metrics on 9327 (`-metricsPort=9327`, as in
  production) so the bundled Prometheus `overleaf-filestore` scrape target
  works (8/8 targets verified up).
- **`bin/doctor`** — SIGPIPE-proof service check (`grep -q` inside a pipefail
  pipeline could SIGPIPE `compose ps` mid-write and falsely report "no
  containers running").
- **`config/variables.env` seed** — full documented coverage: template
  pre-setting (`OVERLEAF_TEMPLATES_USER_ID`, all 12 category names/descriptions
  incl. `TEMPLATE_ALL_*`, FPH, `OVERLEAF_NEW_PROJECT_TEMPLATE_LINKS`), email
  driver/reply-to/TLS-reject/SES, `LINKED_URL_ALLOWED_RESOURCES` /
  `BLOCKED_NETWORKS`, LaTeX user-help wiki (`OVERLEAF_PROXY_LEARN`, `WIKI_URL`),
  session length, anonymous sharing, `ADDITIONAL_TEXT_EXTENSIONS`.
- **Conversion bridge images** in `images.env` (source URL
  `ghcr.io/ayaka-notes/…` where published): `PANDOC_IMAGE`,
  `PDFTOCAIRO_IMAGE` (→ app `CONVERSION_SANDBOX_IMAGE`), `PNG2PDF_IMAGE`,
  with public `sharelatex/*` fallbacks for the two bridges.
- **Bundled build sources** (`lib/images-build/`): grammar-llm, instance-sensor,
  pandoc — so every required image can be produced on an air-gapped/registry-less
  host. Plus `lib/monitoring/` (Prometheus config + Grafana provisioning/dashboards)
  and `lib/tools/download-ngrams.sh`.
- App fragment now injects `PANDOC_IMAGE`, `PNG2PDF_IMAGE`,
  `CONVERSION_SANDBOX_IMAGE` from `images.env`; variables.env seed gains the
  app-side conversion switches (`ENABLE_PANDOC_CONVERSIONS`,
  `ENABLE_PNG2PDF_CONVERSIONS`, `CONVERTER`).
- `doctor` checks the enabled optional sets (images, model/n-gram dirs,
  Grafana password) and the conversion bridge images.


- `config/images.env` — the single resource file for every container image
  name and tag (app, mongo, redis, git-bridge, nginx, seaweedfs, texlive).
- SeaweedFS S3 storage as a managed part of the stack: four services
  (master/volume/filer/s3), generated S3 credentials, buckets, loopback
  S3 API on the host.
- `ayaka-network` — shared internal bridge network for all services; only
  nginx publishes host ports (app direct access only when proxy disabled).
- `ayakalea` app container/hostname with backward-compat network aliases
  `overleaf` and `sharelatex`; Mongo database stays `sharelatex`.
- `bin/pull-texlive` — pull TeX Live images, log, and a cron line for
  automatic updates.
- `OVERLEAF_SESSION_SECRET` generated by `bin/init` (sessions survive
  `bin/up`).
- Healthchecks for app, mongo, redis, git-bridge and seaweedfs services;
  dependency-ordered startup.
- Mongo replica set self-initiation via its healthcheck.

### Fixed (security & correctness audit)
- `nginx.yml` healthcheck: `nginx:alpine` has no `curl` (and the 301→https
  redirect defeats `wget --spider`); now uses `nc -z` against the listeners,
  so the nginx container can actually reach `healthy`.
- `nginx.conf` seed: dual-stack `listen [::]:80/443` so `localhost`-based
  tooling (IPv6-first) works.
- `mongo.yml` healthcheck: the replica-set name was hard-coded to `overleaf`
  in `rs.initiate()`; now interpolates `${MONGO_REPLSET}` (custom names work;
  `MONGO_REPLSET` is now exported for compose interpolation).
- `bin/init`: `config/` is `chmod 700` and the config files `chmod 600` —
  they hold secrets (AWS keys, SMTP, OIDC) and must not be world-readable on
  multi-user hosts.
- `bin/upgrade`: the new image reference is validated against a strict
  allow-list before the `sed` substitution (previously `|`/`&`/newlines in the
  value could corrupt the sed expression or the file).
- `s3-import.py`: `walk_store` now skips symlinked files — a symlink escaping
  the legacy tree could exfiltrate its target into the S3 plane.
- `RC_DEBUG` now warns that its environment dump contains secrets.

### Changed
- All `bin/` scripts now source a single shared core
  (`lib/toolkit-core.sh`); ~30 duplicated bootstrap lines per script are
  gone.
- `lib/compose/*.yml` — one compose fragment per service, assembled by the
  core (replaces `docker-compose.base.yml` + `vars*.yml` split).
- `bin/doctor` rewritten: prerequisites, config sanity, image presence,
  runtime probes (mongo replica set, redis ping, git-bridge /status,
  S3 API, app HTTP) and a clear ok/warn/error report.
- `bin/upgrade` simplified: toolkit (git) → app image (images.env) →
  config backup (`config/__old-version`) → pull/stop/restart.
- `bin/images` reports every configured image and its local presence.
- Image defaults: `ghcr.io/ayaka-notes/overleaf-pro:6.3.4`,
  `ghcr.io/ayaka-notes/overleaf-pro/git-bridge:6.3.4`, `mongo:9.0`,
  `redis:8.10-alpine`, `nginx:alpine3.24-slim`,
  `chrislusf/seaweedfs:latest`, `ghcr.io/ayaka-notes/texlive-full:2026.1`.
- `s3-import.py` + `bin/migrate-s3 wipe` now tolerate missing buckets (create
  on demand) instead of erroring on `NoSuchBucket`.
- `.gitignore` hardened: TLS material, backup archives, and `config/`/`data/`
  are excluded so secrets and data never reach git.
